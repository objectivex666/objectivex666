## 🚀 精选项目

### 🔍 dsh-settings-search

为 DSH 设置面板提供即时搜索能力，快速定位设置页与通用设置项。

**功能特性：**

- **实时搜索**：输入关键词立即过滤所有已注册的设置页与通用设置项
- **拼音联想**：输入拼音首字母（如 `sz`）或全拼即可联想中文设置项
- **意图联想**：直接描述想做的事（如「太亮了」「字太小」），无需知道选项名即可推荐设置项
- **AI 联想**：本地无匹配时，用配置的模型理解搜索意图并推荐设置项
- **页内选项搜索**：直达每个设置页内部的具体选项，结果以「页面 › 选项」面包屑展示
- **点击即达**：选中结果后自动跳转并高亮闪烁目标选项行

**安装：**

```bash
dsh plugin add dsh-settings-search
```

**技术栈：** TypeScript · DSH 插件 API · npm
